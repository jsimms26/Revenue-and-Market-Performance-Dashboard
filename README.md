# Revenue-and-Market-Performance-Dashboard

## Overview

This project displays an interactive Power BI dashboard built to analyze retail sales performance and customer purchasing behavior. The dashboard allows users to explore revenue trends, identify top-performing markets and products, and examine customer purchasing patterns through interactive visualizations and filters.

The goal of this project was to transform raw transactional data into an executive-style dashboard that supports data-driven business decisions.

## Features
- KPI summary cards
- Monthly revenue trend analysis
- Revenue by country analysis
- Top 10 products by revenue
- Customer purchasing behavior scatter plot
- Interactive Month and Country slicers
- Dynamic filtering across all visuals

## Dataset
This dashboard utilizes the **Online Retail II** data set that contains transactions occurring for a UK-based and registered, non-store online retail between 01/12/2009 and 09/12/2011 with 1,067,371 instances and missing values.

The set includes the following information:
- Invoice dates
- Products
- Quantities
- Unit prices
- Customer IDs
- Countries

### Interactive Features
- Month slicer
- Country slicer
- Cross-filtering between visuals

- Excluded records with missing customer IDs from customer-level analysis
- Standardized fields
